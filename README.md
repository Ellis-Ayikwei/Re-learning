# Re-learning

A repository to keep notes from refreshed programming and mathematical concepts for optimization and machine learning.

## Structure

This repository is organized into the following main areas:

- **programming/** - Programming concepts, algorithms, and best practices
- **mathematics/** - Mathematical foundations and advanced topics
- **optimization/** - Optimization techniques and algorithms
- **machine-learning/** - Machine learning concepts, models, and implementations

## Purpose

This repository serves as a personal knowledge base for:
- Refreshing fundamental programming concepts
- Reviewing mathematical principles
- Learning optimization techniques
- Studying machine learning algorithms and applications

## Note Format

Notes are organized by topic and include:
- Theoretical explanations
- Code examples
- Practical applications
- References and resources
