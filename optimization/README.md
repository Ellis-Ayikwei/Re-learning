# Optimization

This directory contains notes on optimization techniques and algorithms used in machine learning and computational problems.

## Topics Covered

### Gradient-Based Optimization
- Gradient Descent
- Stochastic Gradient Descent (SGD)
- Mini-batch Gradient Descent
- Momentum
- Nesterov Accelerated Gradient

### Advanced Optimizers
- AdaGrad
- RMSProp
- Adam
- AdamW
- Learning Rate Schedules

### Convex Optimization
- Convex Sets and Functions
- Linear Programming
- Quadratic Programming
- Constrained Optimization

### Non-Convex Optimization
- Local vs Global Minima
- Simulated Annealing
- Genetic Algorithms
- Particle Swarm Optimization

### Hyperparameter Optimization
- Grid Search
- Random Search
- Bayesian Optimization
- Hyperband

## File Organization

Each topic has its own subdirectory or markdown file with detailed notes, mathematical formulations, and implementation examples.
